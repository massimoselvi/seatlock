# Icons

Logos for the Docker Compose and CI deployment views, from [Simple Icons](https://simpleicons.org/) 16.35.0. Each file is the original SVG with the brand color added as `fill`.

Simple Icons are released under CC0. The logos themselves are trademarks of their owners, and they are used here only to identify the technology in a diagram.

The AWS views use the icons of the Structurizr AWS theme instead. See `../aws-tags.dsl`.
